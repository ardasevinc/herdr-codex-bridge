# Herdr Codex Bridge operating docs

- `herdr-self docs agents`: version-matched instructions for agents.
- `herdr-self docs commands`: bridge-owned commands and operating effects.
- `herdr-self docs commands --json`: machine-readable command metadata.

Use `herdr-self --help` for combined bridge and upstream Herdr help. Use
`herdr-self rebind --help` for the explicit reassociation contract.

These topics are embedded in the installed binary and require no Herdr socket,
Codex identity, plugin state, or network access.
